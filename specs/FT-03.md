# FT-03 Opsi Add-on Terintegrasi

Sumber PRD: Bagian 5 (BL-02), Bagian 6 (FT-03), Bagian 8 (AC-02, AC-03), dan Bagian 11 (add_ons)

## Tujuan
Pelanggan dapat memilih layanan tambahan Antar-Jemput dan Pewangi Premium agar biayanya langsung masuk ke estimasi total.

## Alur
1. Pelanggan melihat dua kotak centang opsi tambahan: `Antar-Jemput` dan `Pewangi Premium`.
2. Pelanggan mengetuk opsi untuk mengaktifkan atau menonaktifkan tambahan tersebut.
3. Jika `Antar-Jemput` aktif, biaya flat `Rp 10.000` ditambahkan dan kolom alamat penjemputan muncul sebagai isian wajib.
4. Jika `Pewangi Premium` aktif, biaya `Rp 2.000` per kg berat ditagih langsung ditambahkan saat berat valid terisi.

## Data
- `CONFIG.layananTambahan.antarJemput` (`T01`, harga `10000`, `flat`, catatan radius maks 5 km)
- `CONFIG.layananTambahan.pewangiPremium` (`T02`, harga `2000`, `per_billed_kg`, catatan Downy Passion / Mystique)

## Aturan dan rumus
- `biayaAntarJemput = antarJemput ? 10000 : 0` (hanya dihitung ketika berat valid >= 0,1 kg).
- `biayaPewangi = pewangiPremium ? Math.round(beratDitagih * 2000) : 0`.
- `biayaTambahan = biayaAntarJemput + biayaPewangi`.

## Input dan validasi
- Kedua opsi bersifat opsional (boleh tidak dipilih sama sekali, dipilih salah satu, atau keduanya).

## Tampilan dan teks
- Judul bagian: `Layanan Tambahan`
- Label `Antar-Jemput` disertai tarif `+Rp 10.000` dan keterangan `Area penjemputan radius max 5 km`.
- Label `Pewangi Premium` disertai tarif `+Rp 2.000 / kg ditagih` dan keterangan `Aroma mewah pilihan tahan lama (Downy Passion / Mystique)`.
- Area sentuh setiap baris minimal 44 x 44 px dan menampilkan state terpilih dengan `border-blue-700 bg-blue-50`.

| ID | Input | Hasil yang diharapkan | Sumber |

| UJ-03-03 | Berat `1,8` kg, centang `Antar-Jemput` + `Pewangi Premium` | `beratDitagih = 3` kg, pewangi `Rp 6.000`, antar-jemput `Rp 10.000` | PRD Kasus A |

## Di luar lingkup
- Perhitungan ongkos kirim dinamis berbasis jarak atau peta.
- Pilihan varian aroma spesifik di luar catatan opsi Pewangi Premium.
